# Source Map

## 1. 목적
이 문서는 현재 프로젝트의 소스 구조와 주요 구성 위치를 정의한다.

이 문서는 기능 설명이 아닌,
코드의 위치와 역할을 기준으로 구조를 파악하고
불필요한 구조 변경을 방지하기 위한 기준 문서이다.

---

## 2. 핵심 원칙

- 현재 폴더 구조를 유지한다
- 파일/폴더의 대규모 이동 및 이름 변경을 금지한다
- 구조 변경은 기능 변경보다 더 높은 위험으로 간주한다
- 모르는 구조는 추정하지 않고 "확인 필요"로 표시한다

---

## 3. 주요 구조

### 3.1 Controllers/
- API 엔드포인트가 정의된 위치
- 외부 요청의 진입 지점

주의:
- 라우트 변경 시 외부 연동 영향 가능성 있음

---

### 3.2 DataStorage/
- 데이터 저장 관련 디렉토리로 추정됨

확인 필요:
- 운영 필수 데이터 저장 여부
- 파일 기반 저장소인지 여부

주의:
- 내부 구조 및 파일 변경 시 데이터 영향 가능성 있음

---

### 3.3 Properties/PublishProfiles/
- 배포 설정 관련 파일 위치

주의:
- 운영 배포 설정 변경 시 서비스 영향 가능성 큼

---

### 3.4 설정 파일

#### appsettings.json
- 기본 설정 파일

#### appsettings.Development.json
- 개발 환경 설정

#### appsettings.Production.json
- 운영 환경 설정

주의:
- 설정 변경 시 전체 시스템 영향 가능성 있음

---

### 3.5 SurveyonApi.csproj
- 프로젝트 빌드 및 패키지 설정 파일

주의:
- 패키지 변경, 빌드 설정 변경 시 전체 영향 가능

---

### 3.6 bin/ / obj/ / .vs/
- 빌드 및 개발 환경 관련 생성 폴더

원칙:
- 직접 수정 금지
- 구조 관리 대상 제외

---

## 4. 구조 흐름 (최소 기준)

Client  
→ Controllers  
→ 내부 처리 로직  
→ 데이터 저장소(DB 또는 DataStorage)

※ 실제 구조는 코드 확인 필요

---

## 5. 변경 위험 구역

### High Risk
- Controllers
- appsettings.Production.json
- 배포 프로파일
- 데이터 저장 관련 경로

### Medium Risk
- appsettings.json
- 개발 환경 설정

### Low Risk
- 문서 파일

---

## 6. 금지 사항

- 폴더 구조 전면 변경 금지
- 파일 일괄 이동/이름 변경 금지
- 설정 파일 구조 변경 금지
- 배포 설정 임의 수정 금지

---

## 7. 문서 범위

이 문서는 구조(위치, 역할)만을 다룬다.

다음 내용은 포함하지 않는다:
