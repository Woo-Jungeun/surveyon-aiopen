## 3. 분석 내용

### 연관규칙(Association Rules) 타당성

- **적합**: 범주형 문항(`ColumnMeta.IsCategorical` = single/multi/rank/custom)
- **부적합**: 오픈형(`open(문자)`), 연속형(`scale`, `open(숫자)`) → 전처리 단계 강제 제외
- **Parquet 변경 감지**: `(pn, parquet_guid)` 조합 기준 — GUID 변경 = 파일 변경으로 판단
- **캐싱 전략**: DB 결과 있음 → 즉시 반환 / 없음 → 분석 실행 후 UPSERT

### 기준값 결정

| 지표 | 설정값 | 근거 |
|---|---|---|
| min_support | 0.05 (최소 0.03 강제) | 응답 5% 이상 등장 항목만 유효 |
| min_confidence | 0.6 | A→B 조건부 확률 60% 이상 |
| min_lift | 1.2 | 우연 대비 1.2배 이상 연관 |
| max_variables | 60 | 조합 폭발 방지 |

    id              SERIAL          PRIMARY KEY,
