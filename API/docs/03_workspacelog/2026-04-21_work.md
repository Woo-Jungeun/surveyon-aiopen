## 2. 주요 작업 내용

### A. 로그인 인증 흐름 수정

| 항목 | 내용 |
|---|---|
| 문제 | `LoginPage.jsx`에서 AES256 암호화 후 전송 → TestAuth 비교 실패(encrypted vs plaintext) |
| 원인 | 암호화는 **백엔드 LoginController**가 담당하는 구조. React는 plaintext 전송이 맞음 |
| 수정 | `encryptAES256()` 제거, plaintext 전송으로 변경 |

| 항목 | 내용 |
|---|---|
| 문제 | `token/validate` 호출 시 headers가 authClient 인터셉터에 의해 빈 값으로 덮어씌워짐 |
| 원인 | 로그인 전 sessionStorage에 token이 없어 인터셉터가 빈 헤더 주입 |
| 수정 | `authClient` → `publicClient`로 변경 + 수동 헤더 명시 |

### C. 연관성 분석 시각화 화면

#### 최종 JSON 구조

```
res.data
└─ resultjson                    ← 1단계 (BaseController 래핑)
    ├─ cached: true/false
    └─ resultjson                ← 2단계 (AiAssociation 결과)
        ├─ meta { pn, rule_count, min_support, min_confidence, min_lift, variable_count, respondent_count, valid_item_count }
        ├─ edges[{ source, target, lift, weight, support, confidence, direction }]
        └─ nodes[{ id, code, size, label, support, variable, code_label }]
```

#### 데이터 매핑 기준

| 항목 | 필드 | 설명 |
|---|---|---|
| 노드 크기 | `nodes[].support` | Support 값 비례 |
| 노드 색상 | `nodes[].variable` | 변수명 기준 그룹 (q20, q40, q50 등) |
| 노드 툴팁 | `nodes[].label` | "SQ4. 직업=전업 주부" 전체 문장 |
| 그래프 내 텍스트 | `nodes[].code_label` | "전업 주부" 짧은 이름 |
| 엣지 두께 | `edges[].lift` (=weight) | Lift 값 비례 |
| 엣지 투명도 | `edges[].confidence` | Confidence 값 비례 |

#### 구현된 화면 구성

```
파라미터 패널
├─ Parquet GUID 입력
├─ 슬라이더: Min Support / Confidence / Lift / Max Variables
├─ [▶ API 실행]  [📊 화면구성]
└─ 뱃지: 노드수 / 규칙수 / 응답수 / 변수수 / 캐시여부

시각화 패널 (3탭)
├─ 🕸 네트워크 그래프 (D3 force-directed)
│   ├─ 드래그 / 줌·팬 / 호버 툴팁
│   └─ 우측 컨트롤: Confidence·Lift 실시간 필터, 라벨 토글
├─ 📋 연관규칙 목록 (Source | Target | Support | Confidence | Lift)
└─ 📝 분석 메타 정보 (pn, GUID, 응답수, 변수수, 규칙수, 파라미터)
```
