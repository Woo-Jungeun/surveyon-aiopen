🕸️ AI 연관성 분석 분과 (AiAssociationController)

다중 응답 패턴 발굴 및 네트워크 연관 규칙 시각화 생성 파이프라인

1. 핵심 기능 및 목적

💡 무자각 연관성 도출 (Apriori Algorithm)

사용자도 스스로 모르는 답변 간의 깊은 상관관계(예: 'A를 산 사람은 B도 산다')를 Apriori/FP-Growth 알고리즘으로 자동 추출합니다.

🚀 네트워크 그래프 시각화 (Nodes & Edges)

추출된 교차 연관성(도수/신뢰도)을 React 기반의 네트워크 그래프 데이터(노드와 엣지 두께)로 전달하여 직관적인 연결망을 렌더링합니다.

🔍 AI 해설 보고서 (Insight Rules)

데이터마이닝으로 추출된 규칙(Rules)을 나열하는데 그치지 않고, LLM을 거쳐 "이 규칙이 현 비즈니스 관점에서 어떤 의미가 있는지" 번역해 제공합니다.

2. 처리 프로세스 흐름도 (Data Pipeline)

1

원핫 인코딩 파싱 (One-Hot Formatting)

파케이 파일에 담긴 복수응답 데이터 배열을 머신러닝(Association Rules) 라이브러리가 연산할 수 있도록 희소 행렬(희소 배열 형태)의 트랜잭션 단위로 변환합니다.

2

연관 규칙 추출 (Association Rules Mining)

Accord.MachineLearning 라이브러리를 활용하여 설정된 최소 지지도(Support) 및 신뢰도(Confidence) 임계값을 넘어선 의미 있는 문항 속성 묶음을 찾아냅니다.

3

Network 노드 및 엣지 생성 (Graph Mapping)

도출된 A -> B 규칙을 기반으로 UI에서 표현 가능한 `nodes`와 `links` 리스트를 구성합니다. Lift(향상도) 수치에 따라 엣지의 두께와 중요도를 자동 스케일링합니다.

4

LLM 전략 보고서 생성 (Summary Request)

규칙 목록을 통계용어 대신 일상 용어로 풀어서 설명하라고 LLM에게 지시를 내리고, 결과 텍스트와 그래프 구조를 조합하여 JSON 형태로 UI에 반환합니다.

3. 프롬프트 엔지니어링 (System Prompt)

당신은 현업 비즈니스 분석 전문가입니다.
제공된 데이터는 설문 참여자들이 특정 문항에서 동시에 선택한 답변들의 연관 규칙(Association Rules)입니다.

[지시사항]
1. 각 규칙(A => B)에 대하여 단순히 '%가 나왔다'로 나열하지 말고, **왜 이런 관계가 형성되었을지 논리적으로 유추**하여 작성하세요.
2. 향상도(Lift)가 높은, 즉 우연이 아니라 매우 이례적으로 강하게 얽혀 있는 특징들을 우선적으로 서술하세요.
3. 분석 내용은 문단 형태로 가독성 좋고 세련되게 요약하세요.

4. 적용 핵심 기술 (Tech Stack)

.NET Core Web API Accord.MachineLearning (Apriori) One-Hot Encoding Algorithm React Force Graph Metadata vLLM (OSS 120B 통신)
