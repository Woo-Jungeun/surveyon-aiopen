👥 AI 응답자 페르소나 세그먼테이션 (AiAnalysis)

머신러닝(K-Means) 기반 고객 군집 자동 분류 및 페르소나 생성 파이프라인

1. 핵심 기능 및 목적

💡 머신러닝 데이터 군집화

수백 혹은 수만 명의 응답 데이터를 벡터화 한 뒤, Microsoft의 ML.NET 프레임워크를 기반으로 특징이 유사한 그룹끼리 묶어(Clustering) 줍니다.

🚀 자동 페르소나 명명 (Persona Naming)

군집별 차이점이 극대화된 문항 데이터를 LLM에게 넘겨, 예를 들어 "단순 1그룹, 2그룹"이 아닌 "가성비를 최우선시 하는 20대 실속형 소비자" 등으로 네이밍해줍니다.

🔍 극단값 필터링 및 전처리

누락된 데이터(결측치)를 채우거나 데이터 정규화를 진행하여 군집 알고리즘의 정확도를 극대화하는 파이프라인이 내장되어 있습니다.

2. 처리 프로세스 흐름도 (Data Pipeline)

1

데이터 피처(Feature) 매핑

파케이 데이터로부터 분석에 사용할 문항들을 골라내어 숫자로 이루어진 특징 벡터(Feature Vector)로 변환/병합합니다.

2

ML.NET K-Means 모델 훈련

사용자가 설정한 K값(예: 3개 그룹)에 따라 응답자 데이터를 K개의 클러스터로 훈련(Train)하고 매핑된 결과를 산출합니다.

3

특성 추출 (Centroid Analysis)

각 그룹(세그먼트)별로 타 그룹과 구별되는 가장 두드러진 응답 패턴의 문항과 답변을 텍스트 요약 문서로 압축합니다.

4

LLM 페르소나 생성 및 UI 응답

특성 요약 텍스트를 VLLM(대형 언어 모델)으로 보내어 매력적인 마케팅 페르소나를 도출하고, JSON 포맷화 하여 방사형(Polar Area) 차트 메타와 함께 프론트엔드로 반환합니다.

3. 프롬프트 엔지니어링 (System Prompt)

당신은 탁월한 데이터 사이언티스트이자 마케팅 페르소나 생성 전문가입니다.
사용자들에게서 K-Means 알고리즘으로 추출한 [특정 군집의 주요 도드라진 응답 특징]이 주어집니다.
