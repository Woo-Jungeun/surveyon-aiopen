💬 AI 챗봇 교차분석 분과 (AiChatbotController)

자연어 질의 기반 실시간 다변량/다차원 데이터 교차분석 자동화 파이프라인

1. 핵심 기능 및 목적

💡 자연어 to 차트 변환 (NLU to Chart)

사용자가 일상어로 "성별을 기준으로 직업과 통신사 결과를 묶어서 보여줘" 라고 입력하면 자동으로 UI에 교차분석 표와 그룹 바 차트를 렌더링합니다.

🚀 혼합 모델링 지원 (Hybrid Crosstab)

단일 배너 뿐만 아니라 변수의 조합(카르테시안 곱, 예: 성별*통신사)을 다중 배너로 확장하여 깊이 있는 분석 도표를 생성합니다.

🔍 유연한 문항 맵핑 (Fuzzy Mapping)

문항번호(SQ2)나 문항이름(성별), 혹은 섞어 쓰더라도 LLM과 메타데이터 동기화를 통해 정확한 변수명(`q10`)으로 치환해주는 매핑 기술이 적용되었습니다.

2. 처리 프로세스 흐름도 (Data Pipeline)

1

변수 사본 제공 (Variables Hint)

사용자의 텍스트(질문)와 함께 현재 파케이 파일 내의 사용 가능한 변수 리스트(`q10(SQ1. 성별)`, `q20` 등) 힌트를 LLM에 제공합니다.

2

LLM 의도 파악 파서 (Intent Parser)

LLM 모델이 시스템 프롬프트의 지시를 받아 사용자의 질문을 분석하고 엄격한 JSON 구조(Stub, Banner 배열 등)로 파싱하여 반환합니다.

3

C# 백엔드 메모리 연산 (Memory Crosstab)

LLM이 반환한 JSON 구조에 맞춰 `ChatAnalyticsService` 엔진이 10종의 다변량 비교(카르테시안 곱, 필터 포함) 로직을 C# LINQ로 계산하여 동적 매트릭스를 생성합니다.

4

JSON 메타 렌더 및 응답 (Render Payload)

연산 결과를 단일 표 구조 및 React UI 랜더링 전용 데이터 셋업 포맷(`ChartMeta`)으로 포장하여 클라이언트에 1초 내 즉시 전송합니다.

3. 프롬프트 엔지니어링 (System Prompt)

당신은 설문조사 자연어 요청을 분석하여, 지정된 교차분석(Crosstab) JSON 규격으로 정확히 변환하는 '데이터 파싱 전문가' 입니다.

[CORE DEFINITIONS]
- Stub (스터브): 교차표의 '행(Row)'. (감지 키워드: 기준, 행, 스터브)
- Banner (배너): 교차표의 '열(Column)'. (감지 키워드: 배너, 열, 기준으로 나눠)

[CROSSTAB MODES]
- mode='banner' : 단일 Stub(행) + 독립적인 Banner(열)들. (최대 5개)
- mode='stub_cart' : 카르테시안 조합 Stub(행) + 독립적인 Banner(열)들.

[OUTPUT FORMAT]
반드시 지정된 JSON 스키마만 반환하십시오.
{
  "mode": "banner",
  "row_var": "q10",
  "banner_vars": ["q20", "q50"]
}

4. 적용 핵심 기술 (Tech Stack)
