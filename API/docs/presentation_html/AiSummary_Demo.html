📄 AI 요약 분석 분과 (AiSummaryController)

설문 결과 데이터 기반 통계 및 인사이트 자동 생성 자동화 파이프라인

1. 핵심 기능 및 목적

💡 자동화된 보고서 텍스트화

수십 개의 문항, 복잡한 교차표 통계 수치(%)를 LLM 기반으로 "텍스트 형태의 보고서(Insight)"로 즉시 전환시켜 줍니다.

🚀 테이블 단위 분산 병렬 처리

메인 스레드가 정지되지 않도록, 개별 문항별 비동기 배치 분석을 실행하며 캐시를 통해 재조회 시 속도를 극대화합니다.

🔍 조건 필터 및 변수 통합

주관식 혹은 특정 속성에 대한 필터(Filter) 결과를 기반으로 서브 요약 엔진이 문맥에 맞는 핵심 사항만 고도화하여 추출합니다.

2. 처리 프로세스 흐름도 (Data Pipeline)

1

메타데이터 맵핑 (Schema Parsing)

설문 정보 및 문항 코드북을 로드하여 문항 내 각 코드값(예: 1=매우만족, 5=매우불만족)과 라벨 정보를 JSON 형태로 정리합니다.

2

통계 전처리 (Pre-Aggregation)

AiSummaryController 내부에서 대상 Parquet 파일을 읽어들여 빈도 또는 기본 교차 비율 테이블을 메모리 연산으로 구성합니다. LLM에 로우 데이터를 보내지 않고, 계산된 요약 표만 보냅니다.

3

LLM 기반 인사이트 도출 (LLM Extraction)

테이블당 독립적인 Prompt를 사용하여 LLM에 API를 비동기로 발송합니다. 가장 높은 퍼센트를 차지하는 주요 경향성과 이례적인 응답 수치를 캐치합니다.

4

결합 및 캐시 반환 (Assemble & Cache)

완성된 여러 문항의 인사이트 텍스트를 하나로 융합하고, 결과를 DB/Cache에 저장하여 다음 요청 시 빠르게 응답합니다.

3. 프롬프트 엔지니어링 (System Prompt)

당신은 탁월한 데이터 분석가이자 전문 리포팅 작가입니다. 
제공되는 JSON 데이터는 특정 설문 문항의 [보기별 빈도 및 백분율] 정보입니다.

[지시사항]
1. 테이블에서 가장 응답률이 높은 핵심 경향성(Top 1~2개)을 중심으로 현상이나 원인을 요약 설명하세요.
2. 수치(%)를 객관적으로 언급하되 단순 숫자 나열을 피하고 통찰력 있는 한 두 문장으로 도출하세요.
3. 데이터에 편향성이 크게 돋보이거나, 소수 응답이지만 이례적인 특이점이 있다면 함께 언급하세요.
4. 분석 결과는 반드시 평어체(~다. ~임.)의 전문적인 보고서 형식으로 작성하십시오.

[입력 데이터 예시]
{ json_table_data }

4. 적용 핵심 기술 (Tech Stack)

.NET Core Web API Parquet.Net (Big Data Parsing) Newtonsoft.Json (JObject, JToken) Task.WhenAll (비동기 병렬 처리) vLLM (OSS 120B 통신) PostgreSQL (메타 & 결과 저장)
