# Non-Negotiables = 무조건 지켜야 하는 불변 규칙

1. 기존 운영 기능을 깨뜨릴 수 있는 변경은 금지한다.
2. 기존 파일을 대규모로 이동/삭제/이름변경하지 않는다.
3. DB 스키마 변경은 별도 승인 없이는 금지한다.
4. secrets, api key, connection string은 코드에 하드코딩하지 않는다.
5. 변경 전 영향받는 파일 목록과 위험요인을 먼저 문서화한다.
6. 구현 전에 반드시 계획서를 작성한다.
7. 한 번에 큰 변경을 하지 않고 작은 단위로 나눈다.
8. rollback 방법이 없는 변경은 진행하지 않는다.
9. 테스트 체크리스트 없이 운영 관련 소스를 수정하지 않는다.
10. 모르면 추측하지 말고 현재 코드와 문서를 기준으로 보수적으로 행동한다.
11. 모든 분석 및 설명은 한국어로 작성한다 (코드/파일명 제외)
12. 프롬프트 실행때 마다 
    (1) 파일명 : 03_workespacelog/YYYY-MM-DD_work.md 
    (2) 내용 : 시간/작업내용/분석내용/코드변경내용/테스트내용/결과/이슈사항
