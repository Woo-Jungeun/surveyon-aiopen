# Pre-Change Checklist

## 목적
코드 변경 전 반드시 확인해야 하는 항목을 정의한다.
이 체크리스트를 통과하지 못하면 변경 작업을 진행하지 않는다.

---

## 1. 기본 확인

- [ ] project_overview.md 확인
- [ ] non_negotiables.md 확인
- [ ] source_map.md 확인

---

## 2. 영향 범위 확인

- [ ] 변경 대상 파일 목록 확인
- [ ] 영향 받는 Controller 확인
- [ ] 영향 받는 Repository 확인
- [ ] 관련 API 영향 여부 확인

---

## 3. DB 영향 확인 (중요)

- [ ] query_inventory.md 확인
- [ ] High Risk 쿼리 포함 여부 확인
- [ ] DELETE / UPDATE 포함 여부 확인
- [ ] DB schema 변경 여부 확인 (있으면 작업 금지)

---

## 4. 위험도 판단

- [ ] Controller 변경 포함 여부
- [ ] Repository 변경 포함 여부
- [ ] appsettings.Production.json 변경 여부
- [ ] 인증/로그인 관련 코드 영향 여부

---

## 5. 롤백 가능 여부

- [ ] 변경 전 상태로 되돌릴 방법 존재
- [ ] 수정 파일 목록 기록
- [ ] 이전 코드 복원 가능 여부 확인

---

## 6. 테스트 가능 여부

- [ ] 테스트 방법 정의
- [ ] 정상 케이스 확인 가능
- [ ] 에러 케이스 확인 가능

---

## 7. 금지 조건 (하나라도 해당되면 중단)

- [ ] DB 스키마 변경 포함됨 → 작업 중단
- [ ] 구조 리팩토링 포함됨 → 작업 중단
- [ ] 영향 범위 불명확 → 작업 중단
- [ ] 롤백 방법 없음 → 작업 중단

---

## 8. 결론

- [ ] 모든 항목 확인 완료 → 작업 진행 가능
- [ ] 일부 항목 미확인 → 작업 보류
